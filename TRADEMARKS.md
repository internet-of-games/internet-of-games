## "Internet of Games"

"Internet of Games" is the name of this open community project. It isn't a registered trademark. The maintainers look after the name for the community, and will pass it to a neutral home if the project moves to one ([GOVERNANCE.md](GOVERNANCE.md#path-to-a-neutral-home)).

- **The licenses don't include the name.** Neither Apache-2.0 (section 6) nor CC BY 4.0 (section 2(b)(2)) licenses trademarks. You're welcome to fork this work and say where it came from, but please give your fork its own name, so nobody mistakes it for this project.
- **Compatible products.** Rules for using the name to describe compatible products will be set as part of [P-0001](problems/P-0001-neutral-governance-and-ip.md) and [P-0026](problems/P-0026-conformance-and-interop-testing.md). Until then, please don't use it in a way that suggests your product is endorsed or certified by the project.

## Working names

Some docs call the portable player document a "player passport". That's a working description, not a name we claim. "PLAYER PASSPORT" is a registered U.S. trademark held by another company ([USPTO record](https://tsdr.uspto.gov/#caseNumber=88697709&caseType=SERIAL_NO&searchType=statusSearch)), so we won't use it as the name of our specification, software or services ([OQ-1](docs/open-questions.md#naming)).

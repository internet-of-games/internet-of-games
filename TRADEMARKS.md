## "Internet of Games"

"Internet of Games" is the name of this open community project. It isn't a registered trademark. Rules for using the name to describe compatible products will be set as part of [P-0001](problems/P-0001-neutral-governance-and-ip.md) and [P-0026](problems/P-0026-conformance-and-interop-testing.md).

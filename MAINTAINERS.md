## Contacting maintainers

- **General questions:** GitHub Discussions.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Please don't use public issues.
- **Code of Conduct reports:** use GitHub's private vulnerability reporting form on this repository (**Security → Report a vulnerability**), and start the title with **"CoC report:"**. Only maintainers can see these reports. You can also use GitHub's own [report abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) tool for content on GitHub.

A dedicated contact address for the project will be added here once it exists.
